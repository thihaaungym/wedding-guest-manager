# 💍 Ever After - မင်္ဂလာဧည့်သည်စာရင်း စီမံခန့်ခွဲမှုစနစ် (Wedding Guest List Manager)

**Ever After** သည် Cloudflare Worker (ဖိုင်တစ်ခုတည်း) ပေါ်တွင် အပြည့်အဝ တည်ဆောက်ထားသော ခေတ်မီ၊ လုံခြုံပြီး အလွန်မြန်ဆန်သည့် မင်္ဂလာဧည့်သည်စာရင်း စီမံခန့်ခွဲမှု Application တစ်ခု ဖြစ်ပါသည်။ မိမိမင်္ဂလာပွဲအတွက် ဧည့်သည်စာရင်းများ၊ ဖိတ်စာအခြေအနေများနှင့် လက်ဖွဲ့မှတ်တမ်းများကို ဖုန်း သို့မဟုတ် ကွန်ပျူတာမှနေ၍ အလွယ်တကူ ထိန်းချုပ်နိုင်မည် ဖြစ်ပါသည်။

## ✨ ပါဝင်သော ပင်မလုပ်ဆောင်ချက်များ (Core Features)

- 📊 **Smart Dashboard (စမတ် ဒက်ရှ်ဘုတ်):** ဧည့်သည်စုစုပေါင်း၊ ရောက်ရှိသူ၊ ဖိတ်စာဝေပြီးသူ ရာခိုင်နှုန်းများနှင့် စုစုပေါင်း လက်ဖွဲ့ငွေပမာဏကို အချိန်နှင့်တပြေးညီ (Real-time) တွက်ချက်ပြသပေးခြင်း။
- 👥 **Guest Management (ဧည့်သည်စီမံခြင်း):** ဧည့်သည်အသစ်ထည့်ခြင်း၊ ပြင်ဆင်ခြင်း၊ ဖျက်ခြင်းနှင့် လိပ်စာ/အုပ်စု/အခြေအနေ အလိုက် အလွယ်တကူ စစ်ထုတ်ရှာဖွေနိုင်ခြင်း။ (အမည်နှင့် လိပ်စာတူပါက ထပ်မဝင်အောင် အလိုအလျောက် တားဆီးပေးသောစနစ် ပါဝင်သည်)။
- 📥 **Excel သွင်း/ထုတ် စနစ် (Smart Excel Sync):** ဧည့်သည် (၁၀,၀၀၀) အထိ Excel ဖိုင်ဖြင့် တစ်ခါတည်း အလွယ်တကူ သွင်း/ထုတ် ပြုလုပ်နိုင်ခြင်း။ (ဖုန်းများ ဟန်းမသွားစေရန် အလိုအလျောက် အပိုင်းလိုက်ခွဲသွင်းပေးသည့် Smart Chunking စနစ် ပါဝင်သည်)။
- 🎨 **Luxury Customization (ဒီဇိုင်း စိတ်ကြိုက်ပြင်ဆင်ခြင်း):** ရွှေရောင်၊ ပန်းရောင် စသည့် အရောင် Theme (၄) မျိုး ရွေးချယ်နိုင်ခြင်း၊ မင်္ဂလာမောင်နှံ၏ အမှတ်တံဆိပ် (Monogram) တင်နိုင်ခြင်း နှင့် အနောက်ခံ အမှုန်လေးများ (Floating Particles) ထည့်သွင်းနိုင်ခြင်း။
- ⚡ **High Performance (အမြန်နှုန်း):** Database တွင် Indexing စနစ်များ ထည့်သွင်းထားသဖြင့် လူသောင်းဂဏန်းရှိနေလျှင်ပင် စက္ကန့်ပိုင်းအတွင်း ရှာဖွေပေးနိုင်ခြင်း။

## 🚀 Cloudflare တွင် အခမဲ့ တည်ဆောက်ရန် လမ်းညွှန် (Setup Guide)

နည်းပညာ အတွေ့အကြုံ မရှိသူများပင် အလွယ်တကူ လိုက်လုပ်နိုင်ရန် အောက်ပါအဆင့် (၄) ဆင့်ကို အစဉ်လိုက် ပြုလုပ်ပေးပါ။

### အဆင့် (၁) - Worker ကုဒ် ထည့်သွင်းခြင်း
1. သင်၏ [Cloudflare Dashboard](https://dash.cloudflare.com/) သို့ လော့ဂ်အင် ဝင်ပါ။
2. ဘယ်ဘက် Menu မှ **Workers & Pages** ကို နှိပ်ပါ၊ ထို့နောက် **Create application** > **Create Worker** ကို နှိပ်ပါ။
3. Worker နာမည်တစ်ခုခုပေးပါ (ဥပမာ- `my-wedding`)။ ပြီးလျှင် **Deploy** ကို နှိပ်ပါ။
4. ထို့နောက် **Edit code** ဆိုသည့် ခလုတ်ကို နှိပ်ဝင်ပါ။ 
5. ဘယ်ဘက်အကွက်ထဲတွင် ရှိနေသော မူလကုဒ်များကို အကုန်ဖျက် (Delete) လိုက်ပြီး၊ ဤပရောဂျက်ထဲမှ `worker.js` ကုဒ်အရှည်ကြီး အပြည့်အစုံကို Copy ကူး၍ Paste ချပါ။ ထို့နောက် ညာဘက်အပေါ်ထောင့်ရှိ **Deploy** (သို့) **Save and deploy** ကို နှိပ်ပါ။

### အဆင့် (၂) - D1 နှင့် R2 ဒေတာဘေ့စ်များ ချိတ်ဆက်ခြင်း
(အောက်ပါဇယားအတိုင်း အတိအကျ ပြုလုပ်ပေးပါ)

| ချိတ်ဆက်ရမည့် အမျိုးအစား | အဆင့်ဆင့် ပြုလုပ်ရန် လမ်းညွှန် |
| :--- | :--- |
| **၁။ D1 Database**<br>*(စာရင်းများ သိမ်းရန်)* | ၁။ ဘယ်ဘက် Menu မှ **Storage & Databases** အောက်ရှိ **D1 SQL Database** ကိုနှိပ်ပါ။<br>၂။ **Create database** ကိုနှိပ်ပြီး `wedding_db` ဟု နာမည်ပေး၍ ဆောက်ပါ။<br>၃။ ခုနက Worker ၏ ပင်မစာမျက်နှာသို့ ပြန်သွားပါ။ **Settings** > **Bindings** သို့သွားပါ။<br>၄။ **Add Binding** > **D1 database** ကိုရွေးပါ။<br>၅။ Variable name နေရာတွင် `DB` ဟု အတိအကျရိုက်ပါ။ Database နေရာတွင် `wedding_db` ကို ရွေးပြီး **Save** နှိပ်ပါ။ |
| **၂။ R2 Storage**<br>*(ဓာတ်ပုံများ သိမ်းရန်)* | ၁။ ဘယ်ဘက် Menu မှ **Storage & Databases** အောက်ရှိ **R2 Object Storage** ကိုနှိပ်ပါ။<br>၂။ **Create bucket** ကိုနှိပ်ပြီး `wedding-logos` ဟု နာမည်ပေး၍ ဆောက်ပါ။<br>၃။ Worker ၏ **Settings** > **Bindings** သို့ ပြန်သွားပါ။<br>၄။ **Add Binding** > **R2 bucket** ကိုရွေးပါ။<br>၅။ Variable name နေရာတွင် `BUCKET` ဟု အတိအကျရိုက်ပါ။ Bucket နေရာတွင် `wedding-logos` ကို ရွေးပြီး **Save** နှိပ်ပါ။ |

### အဆင့် (၃) - စနစ်အား အသက်သွင်းခြင်း (System Activation) ⚠️
ကုဒ်နှင့် Database ချိတ်ဆက်မှု အပြီးသတ်ရန်-
1. မိမိဖုန်း (သို့) ကွန်ပျူတာ၏ Browser တွင် သင့်အက်ပ်၏ လင့်ခ်အနောက်၌ `/api/setup` ဟု ရိုက်ထည့်၍ ဖွင့်ပါ။ 
*(ဥပမာ - `https://my-wedding.yoursubdomain.workers.dev/api/setup`)*
2. မျက်နှာပြင်ပေါ်တွင် **"Database Schema & Indexes Updated Successfully! You can now log in."** ဟု ပေါ်လာပါက (၁၀၀%) အောင်မြင်စွာ တပ်ဆင်ပြီးပါပြီ။

## 📱 အက်ပ် အသုံးပြုနည်း လမ်းညွှန် (User Manual)

သင့် အက်ပ်လင့်ခ် ပင်မစာမျက်နှာသို့ သွားပါ။

*(လုံခြုံရေးအတွက် ဝင်ဝင်ချင်း `Settings` ထဲရှိ Account Security တွင် Password အသစ်ကို ချက်ချင်း ပြောင်းလဲပါ)*။

### ၂။ Excel ဖြင့် စာရင်းအများကြီး တစ်ခါတည်းသွင်းခြင်း (Import)
Guests (ဧည့်သည်စာရင်း) စာမျက်နှာရှိ `Import` ခလုတ်ကို နှိပ်၍ သွင်းနိုင်ပါသည်။ သင့် Excel ဖိုင်၏ ပထမဆုံး အတန်း (Row 1) ခေါင်းစဉ်များကို အောက်ပါအတိုင်း အတိအကျ ပေးထားရပါမည်-
* `Name` (ဧည့်သည်အမည်)
* `Address` သို့မဟုတ် `City` (လိပ်စာ / မြို့)
* `Side` (သတို့သား၊ သတို့သမီး၊ နှစ်ဖက် ဟု ရေးရန်)
* `Status` (Pending, Written, Invited စသဖြင့် အခြေအနေ)
* `Note` (မှတ်ချက် - လိုအပ်မှ ထည့်ရန်)
*(မှတ်ချက် - အမည်နှင့် လိပ်စာ တူညီနေသော ဧည့်သည်များကို စနစ်မှ အလိုအလျောက် ပယ်ချပေးပါမည်)*။

### ၃။ မင်္ဂလာပွဲ အချက်အလက်များ ထည့်ခြင်း
Settings စာမျက်နှာသို့သွား၍ သတို့သား/သတို့သမီး အမည်၊ နေရာ နှင့် ရက်စွဲများကို ဖြည့်စွက်ပါ။ `Upload Couple's Monogram` ကိုနှိပ်၍ သင့်ဖုန်းထဲမှ ဓာတ်ပုံကို လိုသလို အဝိုင်းပုံစံ ဖြတ်တောက် (Crop) ၍ တင်နိုင်ပါသည်။
