# 💍 Ever After - မင်္ဂလာဧည့်သည်စာရင်း စီမံခန့်ခွဲမှုစနစ် (Wedding Guest List Manager)

ဤစနစ်သည် **Cloudflare Workers** (ဖိုင်တစ်ခုတည်း) ပေါ်တွင် အပြည့်အဝ တည်ဆောက်ထားသော လုပ်ငန်းသုံးအဆင့် (Enterprise-grade) မင်္ဂလာဧည့်သည်စာရင်း မှတ်သားသည့် Application ဖြစ်ပါသည်။ **React** (Frontend), **D1** (SQL Database) နှင့် **R2** (Object Storage) တို့ကို အသုံးပြု၍ လုံခြုံမြန်ဆန်စွာ ဖန်တီးထားပါသည်။

---

## ✨ ပင်မလုပ်ဆောင်ချက်များ (Core Features)

- 📊 **Smart Dashboard:** ဧည့်သည်စုစုပေါင်း၊ ရောက်ရှိသူ၊ ဖိတ်စာဝေပြီးသူ စသည့် အခြေအနေများကို ဂရပ်များ၊ ကိန်းဂဏန်းများဖြင့် ရှင်းလင်းစွာ ကြည့်ရှုနိုင်ခြင်း။
- 👥 **Guest Roster:** ဧည့်သည်စာရင်း အသစ်ထည့်ခြင်း၊ ပြင်ဆင်ခြင်း၊ ဖျက်ခြင်းနှင့် လိပ်စာ/အုပ်စု အလိုက် အလွယ်တကူ ရှာဖွေနိုင်ခြင်း။
- 💰 **Gift Tracking:** လက်ဖွဲ့ငွေနှင့် လက်ဖွဲ့ပစ္စည်းများကို စနစ်တကျ မှတ်သားထားနိုင်ပြီး စုစုပေါင်း လက်ဖွဲ့ငွေပမာဏကို တွက်ချက်ပေးခြင်း။
- 📥 **Excel Integration:** ဧည့်သည် (၁၀,၀၀၀) အထိ Excel (`.xlsx`) ဖိုင်ဖြင့် အလွယ်တကူ သွင်း/ထုတ် (Import/Export) ပြုလုပ်နိုင်ခြင်း။
- 🎨 **Luxury UI:** နိုင်ငံတကာစံမီ *Playfair Display* ဖောင့်ကို အသုံးပြုထားပြီး ခမ်းနားလှပသော Glassmorphism ဒီဇိုင်းဖြင့် ဖန်တီးထားခြင်း။
- 🔒 **High Security:** အချက်အလက်များကို လုံခြုံစွာ သိမ်းဆည်းနိုင်ရန် အဆင့်မြင့် Session-based Authentication နှင့် Password Salt လုံခြုံရေးစနစ် ပါဝင်ခြင်း။

## 🚀 အပိုင်း (၁) - Cloudflare တွင် အခမဲ့ တည်ဆောက်ရန် လမ်းညွှန် (Deployment Setup Guide)

သင့်ကိုယ်ပိုင် မင်္ဂလာဧည့်သည်စာရင်း App ကို Cloudflare တွင် အလွယ်တကူ တည်ဆောက်နိုင်ရန် အောက်ပါဇယားပါ အဆင့်များအတိုင်း လုပ်ဆောင်ပါ-

| အဆင့် | လုပ်ဆောင်ရမည့် အမည် | အသေးစိတ် ရှင်းလင်းချက် နှင့် ချိတ်ဆက်နည်းများ |
| :--- | :--- | :--- |
| **၁** | **Cloudflare Worker ဆောက်ခြင်း** | Cloudflare Dashboard သို့ဝင်ပါ။ **Workers & Pages** > **Create Worker** ကိုနှိပ်ပါ။ နာမည်ပေး၍ Deploy နှိပ်ပါ။ ထို့နောက် **Edit Code** ထဲဝင်၍ မူလကုဒ်များကိုဖျက်ကာ မိမိ၏ `worker.js` ကုဒ်အပြည့်အစုံကို Paste ချပြီး **Save and deploy** နှိပ်ပါ။ |
| **၂** | **D1 Database ချိတ်ဆက်ခြင်း** | Menu မှ **Storage & Databases** > **D1 SQL Database** တွင် `wedding_db` အမည်ဖြင့် Database အသစ်တစ်ခုဆောက်ပါ။ ပြီးလျှင် Worker ၏ **Settings** > **Bindings** သို့သွား၍ **Add Binding > D1 database** ကိုရွေးပါ။ <br>• **Variable name:** `DB` <br>• **Database:** `wedding_db` (ရွေးချယ်ပြီး Save နှိပ်ပါ) |
| **၃** | **R2 Storage ချိတ်ဆက်ခြင်း** | Menu မှ **Storage & Databases** > **R2 Object Storage** တွင် `wedding-logos` အမည်ဖြင့် Bucket အသစ်တစ်ခုဆောက်ပါ။ ပြီးလျှင် Worker ၏ **Settings** > **Bindings** သို့သွား၍ **Add Binding > R2 bucket** ကိုရွေးပါ။ <br>• **Variable name:** `BUCKET` <br>• **R2 bucket:** `wedding-logos` (ရွေးချယ်ပြီး Save နှိပ်ပါ) |
| **၄** | **Database အသက်သွင်းခြင်း ⚠️** | မိမိ Browser တွင် Worker ၏ လင့်ခ်အနောက်၌ `/api/setup` ဟု ရိုက်ထည့်၍ ဖွင့်ပါ။ *(ဥပမာ - `https://my-wedding.yours.workers.dev/api/setup`)* မျက်နှာပြင်ပေါ်တွင် **"Database Schema Updated Successfully!"** ဟု ပေါ်လာပါက စနစ်ချိတ်ဆက်မှု အောင်မြင်ပါသည်။ |
| **၅** | **စတင် လော့ဂ်အင် ဝင်ခြင်း** | မိမိ၏ ပင်မ Web Link သို့ ပြန်သွားပါ။ <br>• **Username:** `admin` <br>• **Password:** `admin123` ဖြင့် ဝင်ရောက်ပါ။ <br>*(အရေးကြီး - ပထမဆုံး ဝင်ပြီးသည်နှင့် Settings ထဲတွင် Password ချက်ချင်း ပြောင်းပါ!)* |

## 📱 အပိုင်း (၂) - အက်ပ် အသုံးပြုနည်း လမ်းညွှန် (Detailed User Manual)

### ၁။ ပထမဆုံးအကြိမ် Login ဝင်ခြင်း နှင့် လုံခြုံရေး
- ပင်မလင့်ခ်သို့ သွား၍ မူလအကောင့် (`admin` / `admin123`) ဖြင့် ဝင်ပါ။
- **အရေးကြီး:** Login ဝင်ပြီးသည်နှင့် ညာဘက်အပေါ်ထောင့် သို့မဟုတ် အောက်ခြေရှိ **Settings (ဂီယာပုံ)** သို့သွားကာ အောက်ဆုံးရှိ **Account Security** တွင် မိမိစိတ်ကြိုက် Username နှင့် Password အသစ်ကို ချက်ချင်းပြောင်းလဲပါ။

### ၂။ မင်္ဂလာပွဲ အချက်အလက်များ ထည့်သွင်းခြင်း (Settings)
- **Wedding Details:** သတို့သားနာမည်၊ သတို့သမီးနာမည်၊ မင်္ဂလာရက်စွဲ နှင့် နေရာ (Venue) တို့ကို ဖြည့်စွက်ပြီး Save လုပ်ပါ။
- **Logo တင်ခြင်း:** ဓာတ်ပုံတင်ရန် နေရာတွင် `Upload High-Res Logo` ကိုနှိပ်၍ ပုံတင်ပါ။ အဝိုင်းပုံစံ စိတ်ကြိုက် ချိန်ညှိ (Crop) ပြီး Apply Logo ကို နှိပ်ပါ။ (ပုံများသည် R2 Storage တွင် Quality အပြည့်ဖြင့် သိမ်းဆည်းပေးပါမည်)။
- **App Customization:** အက်ပ်၏ အရောင် Theme (Gold, Rose, Emerald, Blue) များနှင့် Background အလှဆင် Effect (Floating Particles) များကို မိမိစိတ်ကြိုက် ဖွင့်/ပိတ် ရွေးချယ်နိုင်ပါသည်။

### ၃။ ဧည့်သည်စာရင်းများ စီမံခြင်း (Guests)
**Guests (လူပုံစံ)** စာမျက်နှာတွင် အောက်ပါတို့ကို ပြုလုပ်နိုင်သည်-

* **ဧည့်သည် အသစ်ထည့်ရန် (Add):** 
  - `Add` ခလုတ်ကိုနှိပ်ပါ။ သတို့သားဖက်/သတို့သမီးဖက်/နှစ်ဖက်မိတ်ဆွေ ရွေးပါ။
  - နာမည်၊ လိပ်စာ/မြို့ (City)၊ ဖိတ်စာအခြေအနေ (Pending, Written, Invited) တို့ကို ဖြည့်ပါ။
  - မင်္ဂလာဆောင်နေ့တွင် ရောက်ရှိလာပါက **ရောက်ရှိ (Attended)** ကို အမှန်ခြစ် ပေးရပါမည်။ လက်ဖွဲ့ငွေနှင့် ပစ္စည်းများကိုလည်း မှတ်သားနိုင်ပါသည်။
* **Excel ဖြင့် အများအပြားသွင်းရန် (Import):**
  - သင့် Excel ဖိုင် (`.xlsx`) ၏ ခေါင်းစဉ် (Row 1) များကို အောက်ပါအတိုင်း ပေးထားရန် လိုအပ်ပါသည်-
    - `Name` (ဧည့်သည်အမည်)
    - `Address` သို့မဟုတ် `City` (လိပ်စာ)
    - `Side` (ဥပမာ- သတို့သားဖက်, သတို့သမီးဖက်, နှစ်ဖက်)
    - `Status` (Pending, Written, Invited)
    - `Note` (မှတ်ချက်)
  - `Import` ခလုတ်ကိုနှိပ်၍ ထို Excel ဖိုင်ကို ရွေးချယ်လိုက်ပါက စနစ်မှ အလိုအလျောက် Batch စနစ်ဖြင့် ခွဲသွင်းပေးပါမည် (လူသောင်းဂဏန်းအထိ အဆင်ပြေပါသည်)။
* **Excel ဖြင့် ပြန်ထုတ်ရန် (Export):**
  - `Export` ခလုတ်ကို နှိပ်လိုက်သည်နှင့် လက်ရှိဧည့်သည်စာရင်း အားလုံးနှင့် လက်ဖွဲ့မှတ်တမ်းများအားလုံး Excel ဖိုင်အနေဖြင့် ဒေါင်းလုဒ် ကျလာပါမည်။ *(စာရွက်များများ Print ထုတ်လိုပါက ဤ Export ထုတ်ထားသော Excel မှတစ်ဆင့် ထုတ်ရန် အကြံပြုပါသည်)*။
* **အများအပြား ဖျက်ရန် (Bulk Delete):**
  - `Select` ခလုတ်ကိုနှိပ်ပါ။ ဖျက်လိုသော ဧည့်သည်များကို အမှန်ခြစ် ရွေးချယ်ပြီး `ဖျက်မည်` ခလုတ်ကိုနှိပ်ပါ။ လုံခြုံရေးအတွက် Admin Password ပြန်တောင်းပါမည်။

### ၄။ အခြေအနေများ ကြည့်ရှုခြင်း (Dashboard)
- **Dashboard** စာမျက်နှာတွင် ဧည့်သည်စုစုပေါင်း၊ လက်ဖွဲ့ငွေ စုစုပေါင်း၊ ဖိတ်စာပေးပို့မှု အခြေအနေ ရာခိုင်နှုန်းများနှင့် မည်သည့်ဖက်မှ ဧည့်သည် မည်မျှလာသည်ဟူသော ကိန်းဂဏန်းများကို အချိန်နှင့်တပြေးညီ (Real-time) ကြည့်ရှုစစ်ဆေးနိုင်ပါသည်။
